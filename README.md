# SMS Spam Detection

## Overview
SMS Spam Detection using Machine Learning (Logistic Regression)

## Dataset
- Source: Kaggle - SMS Spam Collection Dataset
- Total Messages: ~5,500
- Classes: Ham (Not Spam) & Spam

## Models Used
1. Logistic Regression (Primary)
   - Accuracy: 97.49%
   - ROC-AUC: 0.9934

2. Naive Bayes (Baseline)
   - Accuracy: 97.10%
   - ROC-AUC: 0.9904
